# Colorful Life customer storefront

This repository contains the frontend foundation for the Colorful Life customer storefront.

## Stack

- React and TypeScript
- Vite
- React Router
- Tailwind CSS
- Axios
- Vitest and Testing Library

## Development

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Other available commands:

```bash
npm run lint
npm run test:run
npm run build
```

## Environment

Set the required backend API base URL in a local `.env` file:

```bash
VITE_API_BASE_URL=http://localhost:3000
```

See `.env.example` for a safe example configuration.
